Activity editor

Edit potential activities, care tasks and unexpected events. Drafts stay in this browser; the live game is unchanged until you publish the catalogue.

How publishing works
  1. Edit an event and choose Save event. Add new activities with stable, unique IDs.
  2. Download the validated catalogue as events.json.
  3. Replace also/data/events.json in the GitHub repository and commit. GitHub Pages publishes it.

Keep IDs stable. Removing existing events or changing their timing can make existing saves incompatible. For a large catalogue redesign, keep a backup and plan a save migration. Care stages currently support morning and night tasks; their durations should leave room for the rest of the day.

Selection weight controls how often an optional activity is offered. Outcome risk is the chance of additional health loss after doing it. Unexpected events are never selectable: their daily chance contributes to the emergency roll, which increases with care stage and is capped at 25% overall.
